# SID note table (complete, all octaves)

Exact FREQ LO/HI register values for every equal-tempered note the SID can
reach, C1–B6 (A4 = 440 Hz). One octave higher overflows the 16-bit oscillator,
so B6 is the top.

`Fn` is the 16-bit register value, split into `hi` (FREQ HI, offset `+1`) and
`lo` (FREQ LO, offset `+0`). Set **both** bytes for in-tune notes — the
high-byte-only shortcut lands up to ~30 cents flat.

```
Fout = Fn × Fclk / 2^24     Fclk = 985248 (PAL) / 1022727 (NTSC)
```

`Fn` is linear in pitch, so an octave is exactly ×2 / ÷2. These tables round
**each note independently** rather than doubling, so the `lo` byte is the most
accurate value for that octave (doubling a lower octave can be a step off in the
low byte). Regenerate or convert single values with
[`../scripts/sid-freq.py`](../scripts/sid-freq.py)
(`--note`, `--hz`, `--reg`, `--ntsc`).
